# SQL Baseball Analytics

## Overview
This project analyzes baseball data using the Lahman Baseball Database.  
It focuses on player performance, career statistics, salary trends, and team-level insights using SQL.

---

## Objectives
- Analyze player career length and performance
- Study salary trends across teams and years
- Compare player characteristics (batting hand, height, weight)
- Use advanced SQL techniques for data analysis

---

## SQL Concepts Used
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
- Date & Time Functions
- Joins and Grouping

---

## Analysis Included
- Team spending trends over time
- Cumulative salary analysis by team
- Player career length (debut to final game)
- Players sharing the same birthday
- Batting hand distribution by team
- Height and weight trends across decades

---

## Dataset
This project uses a subset of the Lahman Baseball Database (Maven Advanced SQL dataset), which contains historical baseball data including players, salaries, and schools.

---

## Tools Used
- MySQL
- MySQL Workbench
